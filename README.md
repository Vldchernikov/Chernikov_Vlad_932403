# Лабораторная работа №5: DOM и взаимодействие с элементами страницы

Студент: Черников Владислав  
Группа: 932403  

**Цель:** Научиться манипулировать DOM деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через localStorage.

**Вариант 10.** Тема «Книжный червь и писатель» (список книг на полке).

**Выполнено (в файле `script.js`, подключён к `variant10.html`):**
**Поиск элементов:** `getElementById` — форма, поля ввода, кнопки, контейнер карточек; `querySelector` — элементы внутри карточки, кнопка «Прочитано», последняя карточка; `querySelectorAll` — все карточки книг и все кнопки скрытия блоков.
**Карточки книг:** обложка (для новых книг — обложка-заглушка с первой буквой названия), название, автор и кнопка «Прочитано», которая переключает статус книги.
**Добавление/удаление:** «Добавить книгу» создаёт новую карточку из введённых названия и автора, «Удалить последнюю» убирает последнюю карточку с полки. Счётчик книг обновляется автоматически.
**Манипуляции с DOM:** изменение текста (`textContent`), атрибутов (`setAttribute`, `aria-pressed`, `aria-expanded`, `data-*`), классов (`classList.toggle`), создание (`createElement`, `append`) и удаление (`remove`) элементов.
**Переключение темы:** кнопка в шапке переключает светлую и тёмную тему.
**Скрытие/показ блоков:** кнопки «Скрыть книги» и «Скрыть цитаты» прячут и показывают соответствующие секции, текст кнопки меняется на «Показать…».
**Обработка ошибок:** перед работой проверяется наличие всех нужных элементов (при отсутствии — сообщение в консоль), проверяется заполненность полей формы, удаление с пустой полки не выполняется и выводится сообщение, повреждённые данные в localStorage и недоступное хранилище обрабатываются через `try/catch`, при ошибке загрузки обложки она заменяется заглушкой.
**localStorage:** список книг (вместе со статусом «Прочитано») сохраняется при добавлении, удалении и смене статуса, выбранная тема — при переключении. При загрузке страницы данные восстанавливаются.
