# Лабораторная работа №4: Основы JavaScript

Студент: Черников Владислав  
Группа: 932403  

**Цель:** Познакомиться с синтаксисом JS, базовыми конструкциями и логикой.

**Выполнено (в файле `script.js`, подключён к `variant10.html`):**
**Данные:** Массив из 7 чисел — количество прочитанных страниц по дням: `[64, 15, 48, 72, 20, 55, 38]`.
**Ввод/вывод:** `prompt` запрашивает имя пользователя, `alert` выводит приветствие, результаты расчётов выводятся через `console.log`.
**Функции:** `findMax` — поиск максимума, `filterArray` — фильтрация по условию, `sumArray` — подсчёт суммы. Все три реализованы через циклы.
**Фильтрация:** Отбираются дни с высоким темпом — больше 50 страниц.
**Цикл:** Подсчитываются «ленивые» дни (≤ 20 страниц) и их доля от общего числа дней.
**Условные конструкции:** Проверка введённого имени (пустое значение или отмена — «Гость»), отбор «ленивых» дней, проверка среднего темпа.
**Вывод:**
`alert` — «Всего прочитано X страниц, в Y днях темп был высоким».
Консоль — количество и доля «ленивых» дней, максимум за день, среднее значение.
Доп.: если среднее больше 40 страниц, в консоль выводится «Отличный темп чтения!».

### Результат для текущих данных
Всего прочитано: 312 страниц, дней с высоким темпом: 3, максимум: 72 страницы.
«Ленивых» дней: 2, доля: 28.6%. Среднее: 44.6 страницы в день — выводится «Отличный темп чтения!».
