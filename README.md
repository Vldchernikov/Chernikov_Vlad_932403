## Цель работы
Освоить базовую структуру HTML-документа, семантические теги, работу с текстом, списками, ссылками, изображениями и формами обратной связи

## Структура проекта
Проект состоит из двух связанных между собой веб-страниц:

### 1. `index.html` — Страница «О себе»
Главная страница портфолио, содержащая информацию об авторе

### 2. `variant10.html` — Страница «Книжный червь и писатель» (Вариант 10)
Дополнительная страница, выполненная в соответствии с индивидуальным заданием

## Используемые технологии
* HTML5 Семантические теги (`<header>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
* CSS3 Внутренние стили (`<style>`).
